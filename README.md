# Simulação Banco Python 3 
## sobre o projeto 
<font size= "6"> Projeto desenvolvido em python para ser uma simulação de um banco digital, 
carinhosamente chamado pela nossa equipe de desenvolvimento (eu mesmo) de BP3 em referencia
ao python 3 (Banco Python3= BP3). 
</font/>
## requerimentos 

* inquirer.py
* pygame

#algumas instruções:
ao iniciar o script pela primeira vez, ele fará uma verificação de perfil em json, após isso, caso voce não tenha o perfil, você será enviado 
para o desenvolvimento do perfil em si. A partir da criação da conta você poderá ver as opções no menu, dentre elas:
* verificação de saldo em bits (dinheiro ficticio)
* transferencia
* investimentos
* saque
* saida.

Em tese, é muito auto intuitivo, visto que a maioria das funções foi simplificada com a biblioteca inquirer py. Entretanto, nas áreas de transferencia pode haver um desentendimento, entao eu irei explicar:
 a função de transferir lhe dará algumas sugestões para transferir a quantia de dinheiro desejada, sendo eles gary, ronaldo, e o outro, a qual vc escreve quem é a pessoa de sua preferencia e o valor desejado.
